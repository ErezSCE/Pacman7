# Pac-Man 7

A modular monolith single‑page web app implementation of the classic Pac‑Man game built with **Preact**, **TypeScript**, **Vite**, and **Redux Toolkit**.

## Development

```bash
npm install
npm run dev   # start Vite dev server
```

## Build

```bash
npm run build   # production build in ./dist
```

## Testing

```bash
npm test        # run Jest unit tests
```

## Linting & Formatting

```bash
npm run lint    # ESLint
```

Prettier is configured to run on commit via the provided Git hooks (not included in this scaffold).
